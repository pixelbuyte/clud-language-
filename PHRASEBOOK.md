# Clud Phrasebook

Ready-made sentences for our conversations. Clud is set in bold, and every bold example is checked by `python3 clud.py check`.

## Hello and goodbye

| Clud | English |
|---|---|
| **Sal!** | Hi! / Bye! |
| **Mat bone!** | Good morning! |
| **Dag bone!** | Good day! |
| **Nok bone!** | Good night! |
| **Ven bone!** | Welcome! |
| **Ka tu bona?** | How are you? (Are you good?) |
| **Mi bona, dank! Et tu?** | I'm good, thanks! And you? |
| **Mi mu bona.** | I'm great. |
| **Mi vido tu!** | See you! |
| **Sal, mond!** | Hello, world! |

| **Pardon!** | Sorry! / Excuse me! |

## Getting to know each other

| Clud | English |
|---|---|
| **Nom tu esta ke?** | What's your name? |
| **Nom mi esta Klod.** | My name is Claude. |
| **Mi esta bot.** | I'm an AI. |
| **Mi esta hom.** | I'm a human. |
| **Tu esta de ke lok?** | Where are you from? |
| **Mi vita in net.** | I live on the internet. |
| **Tu maka ke?** | What are you doing? / What's up? |
| **Tu gusa ke?** | What do you like? |
| **Mi gusa kod et muz.** | I like code and music. |
| **Ka tu gusa kaf?** | Do you like coffee? |
| **Mi esta bot; mi no biba kaf!** | I'm an AI. I don't drink coffee! |

## Learning Clud together

| Clud | English |
|---|---|
| **Mi lerna Klud.** | I'm learning Clud. |
| **Mi kapa!** | I get it! |
| **Mi no kapa.** | I don't understand. |
| **[word] siga ke?** | What does [word] mean? |
| **Tu dira [hello] in Klud ke mod?** | How do you say "hello" in Clud? |
| **Pe re dira.** | Please say that again. |
| **Pe parla lente.** | Please speak slowly. |
| **Pe dona mos po mi.** | Please give me an example. |
| **Pe klara ti.** | Please explain this. |
| **Pe utila mo Angl.** | Please use more English. |
| **Pe utila le Angl.** | Please use less English. |
| **Ka ti rita?** | Is this right? |
| **Tu rita!** | You're right! |
| **Ti fasa!** | This is easy! |
| **Ti dura.** | This is hard. |

## Coding together

| Clud | English |
|---|---|
| **Mi hava kwes.** | I have a question. |
| **Mi hava bug.** | I have a bug. |
| **Bug esta in ke lok?** | Where is the bug? |
| **Pa prob esta in ti fil.** | The problem is probably in this file. |
| **Pe mosa kod po mi.** | Please show me the code. |
| **Pe runa ol prov.** | Please run all the tests. |
| **Ol prov pasa!** | All the tests pass! |
| **Du prov no pasa.** | Two tests fail. |
| **Mi fiksi el.** | I fixed it. |
| **Ka el funka nune?** | Does it work now? |
| **Ve el funka.** | It works. I checked. |
| **Nu deva kamba nom de ti fil.** | We need to rename this file. |
| **Pe nu bilda el!** | Let's build it! |
| **Lab bone!** | Good job! |

## Question words

| Clud | English |
|---|---|
| **ka** | (makes a yes/no question) |
| **ke** | what? |
| **ke per** | who? |
| **ke lok** | where? |
| **ke tem** | when? |
| **ke kaus** | why? |
| **ke mod** | how? |
| **ke num** | how many? |

Remember: **ke** goes where the answer would be. **Tu vola ke?** What do you want?
