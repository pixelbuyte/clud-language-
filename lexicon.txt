# Clud lexicon: the single source of truth for every word in the language.
#
# Format:  word | group | English | remember it by
#
# Groups for little words (always exactly 2 letters, never change):
#   people, pointer, amount, starter, reaction, link, relation
# Groups for roots (3+ letters, always end in a consonant, take one ending):
#   beings, mind, talk, action, quality, thing
# Special groups: number, name
#
# After editing, run:  python3 clud.py dict > LEXICON.md && python3 clud.py check
